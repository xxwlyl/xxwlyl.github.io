Publications

02
2026ATC

Chameleon: Adaptive Memory Overcommitment for Disaggregated Virtual Machines

Yilong Luo, Yulong Zhang, Siyuan Xu, Siyi Zhang, Yanwen Xia, Mingyu Wu, Diyu Zhou, Tao Xie, Chenxi Wang

ACM SIGOPS Annual Technical Conference (ATC), 2026

An adaptive memory overcommitment framework for disaggregated VMs that dynamically adjusts page-management granularity to runtime access skewness and defers and batches EPT invalidations, exposing cold memory hidden in huge pages while preserving translation locality and swap efficiency.

2026OSDI

Blowfish: Elastic Virtual Machine Memory for Disaggregated Memory

Yulong Zhang, Yilong Luo, Diyu Zhou, Quan Chen, Quanxi Li, Mosong Zhou, Lei Zhu, Senbo Fu, Qian Peng, Huimin Cui, Xiaobing Feng, Tao Xie, Chenxi Wang

USENIX Symposium on Operating Systems Design and Implementation (OSDI), 2026

A paravirtualized memory overcommitment framework for disaggregated memory that enables μs-scale cold memory reclamation and restoration via guest-level THP-aware hotness tracking and host-level EPT-only reclamation, bypassing costly guest page table and I/O page table modifications.
